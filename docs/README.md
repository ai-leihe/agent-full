## 一分钟速览

### 现状（起点）

`agent-full` 是一个**多 Agent 串联 + 插拔式 Skill 流水线**平台，已具备知识库的**摄取骨架**：

```
文件上传 → 清洗 → 切片 → 向量化 → 入库 → 相似度检索
```

其四层抽象（`Skill` / `Agent` / `Pipeline` / `PipelineContext`）+ **运行时编排**（草稿 / 契约诊断 / 自动补全 / 方案存档）是稀缺资产。

平台侧还已具备一套可运营的工作台：**概览看板、技能库（插件启停 + 沙盒试跑）、运行记录（轨迹 / 重放 / 持久化）、知识库（索引浏览与检索）、系统设置（Schema 驱动 + 模型供应商）、账号与权限（登录 / 角色 / 会话管理）**，并带全局登录校验中间件与 144 个自动化用例。

> 实现现状、目录结构与**完整接口清单**见 [平台实现说明与接口文档](../README.md)。

### 核心结论

> **内核优于竞品，产品化落后于竞品。**

四块必须补的地基：**混合检索**、**Rerank**、**权限体系**、**持久化向量库**。

### 产品定位

> 一款**可私有化部署、链路可编排、效果可度量**的企业级 RAG 知识库平台。
>
> 价值主张：**把 RAG 流水线从黑盒变成白盒**——每条链路都可看见、可调整、可评测。

### 差异化亮点

| 亮点 | 说明 |
|---|---|
| **白盒 RAG 流水线** | 检索链路完全可见、可调、可 A/B（竞品多为黑盒） |
| **检索测试台** | 实时查看每一跳耗时与结果，现场调参看效果 |
| **切片可视化与人工干预** | 切片可预览、可编辑、可锁定（借鉴 RAGFlow） |
| **效果评测闭环** | 内置 RAGAS + 黄金集 + 回归门禁 |
| **零成本复用编排能力** | 查询链路直接复用现有 `Orchestration` 抽象 |

### 交付节奏

| 版本 | 主题 | 关键词 |
|---|---|---|
| **v1.0 MVP** | 能用且敢用 | 混合检索 + Rerank + 权限 + 问答 + 检索测试台 |
| **v1.5** | 好用且可运营 | 多源采集 + RAGAS 评测 + 运营看板 + 渠道集成 |
| **v2.0** | 深水区与生态 | GraphRAG + 多模态 + 插件市场 + 国产化 |

## 关键设计决策（ADR 摘要）

| # | 决策 | 理由 |
|---|---|---|
| ADR-1 | 权限过滤**前置**到召回阶段 | 防泄露 + 避免 Top-K 名额被无权限结果挤占 |
| ADR-2 | 融合用 **RRF** 而非加权求和 | 无需归一化，量纲不可比问题自动规避，鲁棒 |
| ADR-3 | 向量库走**协议替换**，不自研 | 成熟方案多（pgvector/Qdrant/Milvus），自研无收益 |
| ADR-4 | Embedding 私有化默认 **BGE-M3** | 中文强 + 可离线 + 支持稠密与稀疏 |
| ADR-5 | **复用 `Orchestration`** 做链路配置 | 已有能力，几乎零成本 |
| ADR-6 | GraphRAG **推迟到 V2** 且按场景启用 | 索引成本是传统 RAG 的 10–50 倍 |
| ADR-7 | 生命周期用**状态机**而非布尔标记 | 支持完整治理流程 |
| ADR-8 | 切片支持**人工编辑 + 锁定** | 高价值体验，人工修正不被重索引覆盖 |
| ADR-9 | **不重构内核**，只做加法 | 三红线：不破坏抽象、复用优先、能力可插拔 |

## 改造清单要点

共 20 项改造，**以新增为主，无需重构**：

- **新增槽位（11 项）**：`connector` / `enhancer` / `retriever` / `fusion` / `reranker` / `rewriter` / `guard` / `generator` / `postprocess` 等
- **新增服务层（4 项）**：知识库 / 文档 / 切片 / 检索 / 问答 / 评测 / 分析
- **新增前端（1 项）**：管理控制台 + 问答端
- **改造现有（4 项）**：parser 升级、切片扩充、增量更新、编排工作台扩展（**近乎零成本**）

> **最大杠杆**：现有 `Orchestration` 抽象可直接承载"查询链路编排"，这是竞品难以快速复制的能力。
